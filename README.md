# WorkBuddy 启动引导（教师版）

给老师的「开箱配置」引导文件。选对应学段的那一份，拖进 WorkBuddy 对话框，它会一步步带你把工作环境配好。全程约 10 分钟，不需要懂技术。

## 选哪个版本

| 你在教 | 用这个文件 |
|---|---|
| 小学 | [WorkBuddy启动引导-小学教师版.md](WorkBuddy启动引导-小学教师版.md) |
| 高中 | [WorkBuddy启动引导-高中教师版.md](WorkBuddy启动引导-高中教师版.md) |
| 中职 | [WorkBuddy启动引导-中职教师版.md](WorkBuddy启动引导-中职教师版.md) |
| 大学 / 高职 | [WorkBuddy启动引导-大学教师版.md](WorkBuddy启动引导-大学教师版.md) |

## 怎么用

1. 点开上面属于你的那份文件，把它下载到本地（或直接复制全文）
2. 新开一个 WorkBuddy 对话
3. 把文件拖进对话框（或作为附件上传）
4. 发一句话：**「按文件里的指示开始」**
5. 跟着它一步步回答，每步它会先跟你确认再往下走

## 做完你会得到

- 4 个记忆文件：`USER.md`（你是谁）、`SOUL.md`（它的说话方式和底线）、`MEMORY.md`（跨项目的硬规则）、`EVOLUTION.md`（错题本）
- 一套按用途分好的本地工作区文件夹
- 可选：一个本地知识库，放课件、文献、常用材料

以后换话题不用反复自我介绍，它记得你。

## 它会问你什么

6–7 个问题，一轮问完：怎么称呼你、教什么年级什么科目、最想让它帮你做哪 3 件事、有没有不想让它碰的话题、回复要简短还是详细、（大学版多问一条岗位侧重）、要不要建知识库。

## 隐私说明

全程**不会**向你索要：身份证号、银行卡、密码、住址明细、学生及家长个人信息、未发表的论文或评审材料。如果它问了，直接拒绝并告诉它「这条不在引导范围内」。
